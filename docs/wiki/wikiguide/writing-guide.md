# Wiki執筆ガイド

すみれさばWikiへようこそ！
ここでは、新しいページを追加する方法と、基本的なルールについて解説します。
具体的なMarkdownの書き方については、[Markdownチートシート](/wiki/general/markdown-cheatsheet) をご覧ください。
また、Markdownの練習には [砂場（練習ページ）](/wiki/general/sandbox) を利用できます。

## ページの追加方法

Wikiはファイルベースで管理されています。
`docs/wiki/` フォルダの中にMarkdownファイル (`.md`) を追加するだけで、自動的にページとして認識されます。

### ディレクトリ構成
```text
docs/
  wiki/
    category-name/     <- カテゴリID（フォルダ名がカテゴリ名になります）
      page-name.md     <- ページID（ファイル名がURLになります）
```

### 手順
1. `docs/wiki/` 以下の適当なカテゴリフォルダ（例: `general` や `minecraft`）を開きます。
2. 新しい `.md` ファイルを作成します（例: `rules.md`）。
3. ファイルの**一番最初の行**に `# タイトル` を書きます。これがサイドバーに表示される名前になります。

## 画像の使い方

画像をWikiに貼りたい場合は、以下の手順で行います。

1. 画像を `public/wiki/images/` フォルダに保存します。
2. Markdownで以下のように記述します。

```markdown
![画像の説明](/wiki/images/ファイル名.png)
```

Wiki内の画像は自動的にスマホ対応（画面幅に合わせて縮小）され、角丸・影付きで表示されます。

---

## 執筆のルール

*   **見出しを活用する**: 読みやすくするために、適切な見出し（`##` や `###`）を使いましょう。
*   **改行について**: 普通の改行は無視されます。段落を変えたい場合は、**1行空行**を挟んでください。
*   **ネタバレ**: ストーリーの核心に触れる内容などは、`<details>` タグを使って隠すことを推奨します。
