# Wiki執筆ガイド

すみれさばWikiへようこそ！
ここでは、新しいページを追加する方法と、基本的なルールについて解説します。
具体的なMarkdownの書き方については、[Markdownチートシート](/wiki/wikiguide/markdown-cheatsheet) をご覧ください。

## ページの追加方法

Wikiはファイルベースで管理されています。
`docs/wiki/` フォルダの中にMarkdownファイル (`.md`) を追加するだけで、自動的にページとして認識されます。

### ディレクトリ構成
```text
docs/
  wiki/
    category-name/     <- カテゴリID（フォルダ名がカテゴリ名になります）
      page-name.md     <- ページID（ファイル名がURLになります）
```

### 手順
1. `docs/wiki/` 以下の適当なカテゴリフォルダ（例: `general` や `minecraft`）を開きます。
2. 新しい `.md` ファイルを作成します（例: `rules.md`）。
3. ファイルの**一番最初の行**に `# タイトル` を書きます。これがサイドバーに表示される名前になります。

## 画像の使い方

Wikiに画像を貼る手順は以下の通りです。

### 1. 画像ファイルを配置する
プロジェクト内の **`public/wiki/images/`** フォルダに画像ファイルを置いてください。

```text
public/
  wiki/
    images/
      my-image.png   <-- ここに置く
```

※ もしフォルダがない場合は作成してください。

### 2. Markdownで表示する
以下のように書くと表示されます。

```markdown
![画像の説明](/wiki/images/my-image.png)
```

**サイズ指定をする場合:**
Markdownには標準でサイズ指定の機能がありません。
サイズを変えたい場合は、HTMLタグを使います。

```html
<img src="/wiki/images/my-image.png" width="200" alt="サイズ指定" />
```

※ `width="300"` のように幅だけ指定すれば、高さは自動で調整されます。

*   パスは必ず `/wiki/images/` から始めてください。
*   画像は自動的にレスポンシブ（スマホ対応）になり、角丸と影がつきます。

## 執筆のルール

*   **見出しを活用する**: 読みやすくするために、適切な見出し（`##` や `###`）を使いましょう。
*   **改行について**: Enterキーで改行すれば、そのまま改行として表示されます。
*   **段落を変える**: 段落を分けたい（行間を広げたい）場合は、**1行空行**を挟んでください。
*   **ネタバレ**: ストーリーの核心に触れる内容などは、`<details>` タグを使って隠すことを推奨します。
