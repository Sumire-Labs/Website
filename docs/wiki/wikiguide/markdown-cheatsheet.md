# Markdownチートシート

Wikiで使えるMarkdown記法の一覧です。
「実際にどう書くか（コード）」と「どう表示されるか（プレビュー）」を並べています。

## 基本的な記法

### 見出し
記事の構造を作るのに使います。

**書き方:**
```markdown
# タイトル (H1)
## 大見出し (H2)
### 中見出し (H3)
```

**プレビュー:**
(実際の表示はページ上部のタイトルなどを参照)

---

### 太字・斜体
強調したい部分に使います。

**書き方:**
```markdown
**とても重要なこと**
*補足的なこと*
~~間違ったこと~~
```

**プレビュー:**
**とても重要なこと**
*補足的なこと*
~~間違ったこと~~

---

### リスト
項目を列挙するときに使います。

**書き方:**
```markdown
- りんご
- みかん
  - 愛媛県産
  - 和歌山県産

1. 手順1
2. 手順2
```

**プレビュー:**
- りんご
- みかん
  - 愛媛県産
  - 和歌山県産

1. 手順1
2. 手順2

---

### リンクと画像
他のページに飛ばしたり、画像を表示します。

**書き方:**
```markdown
[Google](https://google.com)
![画像添付](/wiki/images/sample.png =100x100)
![幅だけ指定](</wiki/images/sample.png =300x>)
```

**プレビュー:**
![特水](/wiki/images/tokusui.png =128x)

---

### 引用
誰かの発言や、外部からの引用に使います。

**書き方:**
```markdown
> これは引用です。
> 複数行も可能です。
```

**プレビュー:**
> これは引用です。
> 複数行も可能です。

---

## コードの表示

### １行コード
文章の途中でコマンドなどを書くときに使います。

**書き方:**
\`\`\`
`npm install` を実行してください。
\`\`\`

**プレビュー:**
`npm install` を実行してください。

### コードブロック（複数行）
プログラムのコードや設定ファイルの中身を書くときに使います。
言語名（`javascript`など）を指定すると色がつきます。

**書き方:**
\`\`\`javascript
console.log("Hello");
const x = 10;
\`\`\`

**プレビュー:**
```javascript
console.log("Hello");
const x = 10;
```

---

## リッチな機能 (GitHub Flavored)

### タスクリスト
進捗管理に使えます。

**書き方:**
```markdown
- [x] 完了したタスク
- [ ] 未完了のタスク
```

**プレビュー:**
- [x] 完了したタスク
- [ ] 未完了のタスク

### 表（テーブル）
データを整理して見せるときに使います。

**書き方:**
```markdown
| 名前 | 年齢 | 職業 |
| :--- | :---: | ---: |
| Alice | 20 | Engineer |
| Bob | 25 | Designer |
```

**プレビュー:**
| 名前 | 年齢 | 職業 |
| :--- | :---: | ---: |
| Alice | 20 | Engineer |
| Bob | 25 | Designer |

### 折りたたみ (ネタバレ防止)
長すぎる内容や、ネタバレを隠すのに便利です。

**書き方:**
```html
<details>
<summary>ここをクリックして表示</summary>

隠されていた中身です。
</details>
```

**プレビュー:**
<details>
<summary>ここをクリックして表示</summary>

隠されていた中身です。
</details>

### アラート
閲覧者に注意を促すときに使います。

**書き方:**
```markdown
> [!NOTE]
> これはノートです。

> [!WARNING]
> これは警告です。
```

**プレビュー:**
> [!NOTE]
> これはノートです。

> [!WARNING]
> これは警告です。
