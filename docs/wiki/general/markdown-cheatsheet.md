# Markdownチートシート

Wikiで使えるMarkdown記法の一覧です。
コピー＆ペーストして使ってください。

## 基本的な記法

| 機能 | 書き方 | 表示例 |
| :--- | :--- | :--- |
| **見出し** | `## タイトル` | **タイトル** |
| **太字** | `**太字**` | **太字** |
| **斜体** | `*斜体*` | *斜体* |
| **打消し** | `~~打消し~~` | ~~打消し~~ |
| **リスト** | `- 項目` | • 項目 |
| **番号** | `1. 項目` | 1. 項目 |
| **リンク** | `[文字](URL)` | [文字](URL) |
| **画像** | `![説明](パス)` | (画像が表示されます) |
| **引用** | `> 引用` | <blockquote>引用</blockquote> |
| **コード** | `` `コード` `` | `コード` |
| **区切り** | `---` | <hr> |

## リッチな機能 (GitHub Flavored)

### タスクリスト
```markdown
- [x] 完了したタスク
- [ ] 未完了のタスク
```

### シンタックスハイライト
```markdown
\`\`\`javascript
console.log("Hello, World!");
\`\`\`
```

### 表（テーブル）
```markdown
| 左揃え | 中央揃え | 右揃え |
| :--- | :---: | ---: |
| A | B | C |
```

### 折りたたみ
```html
<details>
<summary>ここをクリック</summary>
中身が表示されます
</details>
```

### アラート
```markdown
> [!NOTE]
> ノート

> [!WARNING]
> 警告
```
