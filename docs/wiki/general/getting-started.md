# Wikiの始め方

すみれさばWikiへようこそ！このページでは、Wikiの使い方について説明します。

## Wikiとは

すみれさばの各種情報をまとめたドキュメントサイトです。ゲームサーバーの情報、ルール、ガイドなどを確認できます。


## ナビゲーション方法

### デスクトップ
左側のサイドバーからカテゴリーとページを選択できます。

### モバイル
右下の丸いボタンをタップするとサイドバーが開きます。

## ページの見方

各ページには以下の情報が含まれています：
- タイトル
- 本文（Markdown形式）
- リンク（外部リンクは新しいタブで開きます）
