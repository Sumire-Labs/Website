# 全体ルール

すみれさばコミュニティの基本ルールです。

## 基本ルール

1. **相互尊重**: すべてのメンバーを尊重してください
2. **荒らし禁止**: スパム、荒らし行為は禁止です
3. **適切なコミュニケーション**: 不適切な言葉遣いは控えてください
4. **個人情報の保護**: 他人の個人情報を無断で公開しないでください

## 違反時の対応

ルール違反が確認された場合、以下の対応を取る場合があります：

- 警告
- 一時的な権限制限
- サーバーからの除名

## 質問がある場合

ルールについて不明な点があれば、モデレーターに気軽にお問い合わせください。
