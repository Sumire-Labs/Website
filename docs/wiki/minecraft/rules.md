# Minecraftサーバールール

すみれさばMinecraftサーバーのルールです。

## サーバールール

1. **PvP**: 合意のないPvPは禁止です
2. **建築**: 他人の建築物を無断で破壊・改変しないでください
3. **アイテム**: 他人のチェストから無断でアイテムを取らないでください
4. **チート禁止**: チートMOD、X-Rayなどの使用は禁止です

## 推奨事項

- 大規模な建築をする際は、事前に場所を確認しましょう
- 公共施設は皆で使いやすいように整備しましょう
- 資源は計画的に採取しましょう

## トラブル時の対応

問題が発生した場合は、すぐにモデレーターに報告してください。
